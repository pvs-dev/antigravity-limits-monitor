# ⚡ Antigravity Limits Monitor

Компактный десктопный виджет-оверлей поверх всех окон и утилита системного трея для мониторинга лимитов и квот Google Antigravity в реальном времени.

## ✨ Особенности

- **🎯 Компактный Floating HUD (Always-on-Top)**:
  - Микро-шкалы (прогресс-бары) и процентное значение для каждой модели.
  - Мелкий четкий шрифт, настраиваемая прозрачность и цветовая тема.
  - Таймер обратного отсчета до времени сброса лимита (UTC).
  - Свободное перетаскивание мышью в любое место экрана (с автосохранением позиции).
- **🔄 Умное обновление**:
  - Мгновенное обновление по клику на оверлей.
  - Автоматическое обновление в фоне (по умолчанию каждые 30 минут).
- **🔔 Иконка в системном трее**:
  - Быстрый просмотр статуса аккаунта и остатка лимитов по наведению.
  - Меню: *Обновить*, *Скрыть/Показать*, *Настройки*, *Выход*.
- **⚙️ Окно настроек (Settings Dialog)**:
  - **Авторизация и Связь**: автоматическое определение PID, CSRF-токена и RPC порта `language_server`, отображение плана и кредитов.
  - **Внешний вид**: настройка цветов фона, текста, шкалы (для >50%, 20-50%, <20%), размера шрифта и прозрачности.
  - **Модели**: включение/выключение моделей, группировка одинаковых пулов (High/Med/Low).
  - **Таймеры**: выбор интервала автообновления (1, 5, 15, 30, 60 мин).

## 🚀 Запуск

### Запуск в 1 клик
Запустите файл `run.bat` или выполните:

```powershell
python main.py
```

Для бесшумного запуска в фоне (без окна терминала):
```powershell
pythonw main.py
```

---

## 🛠️ Управление
- **Клик левой кнопкой по оверлею**: Мгновенно обновить лимиты.
- **Зажатие ЛКМ и перемещение**: Перетащить виджет по экрану.
- **Двойной клик ЛКМ**: Открыть настройки.
- **Правый клик по оверлею**: Быстрое контекстное меню.
- **Клик по иконке в трее**: Скрыть / показать оверлей.
- **Правый клик по иконке в трее**: Меню управления и выход.
